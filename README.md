# OnAir releases

Installers for **OnAir**, radio automation for FM and internet stations.

**Install:** download the latest `OnAir-Setup-<version>.exe` from
[Releases](https://github.com/AlegbeSamuelAyoola/onair-releases/releases/latest) and run it. No admin
rights are needed.

**Updates:** an installed OnAir checks this page itself and offers new versions in its status
bar. Installing an update upgrades the existing installation in place and keeps your settings
and logs.

The source code is private. This repository only hosts the release installers.
